# SpotifyMusicCoverBar

A lightweight macOS app to control Spotify directly directly from the menu bar.
You can finally see the artwork of the song that is currently playing.

<p align="center">
  <img width="500" src="/images/img_01.png" alt="small icon in bar" style="border-radius:20px">
</p>

### Features:
- Mini Player: Displays current track, artist, and live spinning vinyl cover
- Progress Bar: Real-time track duration display
- Playback Controls: Play, pause, skip forward, and skip backward
- Standalone: Runs completely in the background (no dock icon)

### Installation:
1. Download SpotifyMusicCoverBar.zip below and unzip it
2. Drag SpotifyMusicCoverBar.app into your "/Applications" folder
3. Launch the app and grant the Spotify control permission on first start
